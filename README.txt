PROJETO ONG ESPERANÇA — EXPERIÊNCIA PRÁTICA I

Estrutura:
- index.html
- projetos.html
- cadastro.html
- style.css
- imagens/ong.jpg
- imagens/projetos.png
- imagens/voluntariado.webp

O projeto é uma simulação acadêmica de um site de ONG.
Os dados de contato e o formulário são fictícios e servem apenas para demonstração.

As imagens desta versão são fotográficas em estilo realista, geradas especificamente
para a atividade acadêmica. Não representam uma ONG real.

Para testar:
1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra index.html no navegador.
4. Teste os links e o formulário.
5. Valide os três arquivos HTML no W3C Validator.
